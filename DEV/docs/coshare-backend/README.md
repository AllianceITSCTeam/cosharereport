# coshare-backend/ — Tài liệu thô từ repo backend chính

Copy output của `ck:doc` (chạy bên repo backend CoShare) vào đây.

- Giữ **nguyên bản**, không chỉnh sửa — đây là nguồn tham chiếu.
- Đặt tên theo module cho dễ tra, ví dụ: `orders.md`, `affiliate-commission.md`, `user-login.md`.
- Khi tìm được logic quan trọng cho report → chắt lọc lại vào `../db/conventions.md`
  (đừng bắt mỗi lần làm report phải đọc lại toàn bộ file thô).

> Chưa có file nào. Sau khi bạn chạy `ck:doc` và copy vào, xoá dòng này.
